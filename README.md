# Portafolio de Ciencia de Datos

Este repositorio contiene el código fuente de mi portafolio profesional y académico. El sitio reúne evidencias de proyectos desarrollados durante la Licenciatura en Ingeniería en Ciencia de Datos en la Universidad Veracruzana, abarcando desde análisis de gobernanza de datos y procesamiento satelital, hasta modelación de series de tiempo e inferencia estadística.

## Contenido del Portafolio

* **Evolución de la Protección de Datos en América Latina**  
  Análisis cuantitativo y cualitativo de marcos normativos utilizando microdatos del Barómetro Global de Datos 2024[cite: 7].  
  * **Reconocimiento:** Segundo Lugar Internacional – Global Data Barometer Data Visualization Challenge[cite: 7].  
  * **Autores:** David Martínez Galicia, Eidan Enrique Juárez García, Dalia Abigail Uscanga Gutiérrez[cite: 7].

* **Monitoreo Ambiental Integrado con Datos Satelitales NASA**  
  Sistema interactivo para la integración de datos satelitales (VIIRS, mallas NetCDF de CH4 y ozono)[cite: 7].  
  * **Reconocimiento:** Segundo Lugar – Datathon Día de los Datos Abiertos 2026 (FEI UV)[cite: 7].  
  * **Autores:** Angel Martinez Mendez, Eidan Enrique Juárez García, Dalia Abigail Uscanga Gutiérrez[cite: 7].

* **Transición Energética y Emisiones en el Pacífico**  
  Plataforma web para la visualización cartográfica de matrices energéticas y patrones de emisión (2000–2023).  
  * **Marco:** Proyecto presentado en el Pacific Data Viz Challenge.  
  * **Autores:** David Martínez Galicia, Eidan Enrique Juárez García, Dalia Abigail Uscanga Gutiérrez, Angel Martinez Mendez.

* **Análisis y Pronóstico de Defunciones en el Estado de Veracruz (1994–2029)**  
  Estudio demográfico univariado mediante la metodología Box-Jenkins aplicado a registros del INEGI[cite: 13].  
  * **Modelo:** ARIMA(1,1,0)[cite: 13].  
  * **Autora:** Dalia Abigail Uscanga Gutiérrez[cite: 13].

* **Emisiones de CO2 y Variación de Temperatura en México (ODS 13)**  
  Evaluación de tendencias de emisiones sectoriales frente a anomalías térmicas[cite: 8].  
  * **Presentación:** XV Foro Internacional de Estadística Aplicada[cite: 8].  
  * **Autores:** Dalia Abigail Uscanga Gutiérrez, Eidan Enrique Juárez García, Angel Martinez Mendez, Jesús Hernández[cite: 8].

* **Demanda de Azúcar en México: Modelación SARIMA**  
  Pronóstico de series agroindustriales con datos de CONADESUCA[cite: 1].  
  * **Modelo:** SARIMA(1,0,1)(0,1,1)[12][cite: 1].  
  * **Autores:** Angel Martinez Mendez, Eidan Enrique Juárez García, Laura Tonil, Dalia Abigail Uscanga Gutiérrez[cite: 1].

* **Comparación de Algoritmos para el Ajuste de un Modelo Lineal**  
  Evaluación experimental de algoritmos de optimización (Algoritmo Genético, Hill Climbing, DFS) frente a MCO[cite: 2].  
  * **Autores:** Dalia Abigail Uscanga Gutiérrez, Eidan Enrique Juárez García, Angel Martinez Mendez[cite: 2].

* **Estilo de Vida y Rendimiento Académico en Ciencia de Datos**  
  Investigación inferencial sobre hábitos universitarios aplicando el instrumento FANTASTIC y pruebas no paramétricas[cite: 5].  
  * **Autores:** Eidan Enrique Juárez García, Angel Martinez Mendez, Dalia Abigail Uscanga Gutiérrez, Dr. Juan Ruiz[cite: 5].

## Estructura Técnica

El proyecto está construido de forma nativa sin dependencias externas pesadas:

* **HTML5 y CSS3:** Maquetación limpia en paleta clásica beige y azul marino.
* **JavaScript Vanilla:** Lógica para el filtrado de proyectos por categoría y apertura de modales con fichas técnicas.
* **Tipografía:** Libre Baskerville y Plus Jakarta Sans vía Google Fonts.
